# Automação de Posts — Solution Certificado Digital

Pipeline que gera imagens/carrosséis para Instagram e Facebook inspirados em padrões de concorrentes do segmento de certificação digital, respeitando a identidade visual da Solution, com aprovação humana via Telegram antes da publicação.

## Status

🚧 Em construção — plano definido, credenciais e assets iniciais recebidos.

## Estrutura

```
assets/brand/        → logo da Solution (fundo claro/escuro)
config/brand.json     → paleta de cores e caminhos do logo
config/competitors.json → perfis de referência (concorrentes)
docs/                 → guias de setup (Meta API, Telegram bot)
```
